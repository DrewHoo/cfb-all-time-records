# Project notes for the agent

- What it is: CFB All-Time Records, all 136 FBS football programs on one board at https://drewhoover.com/cfb-all-time-records/. The sentence picks the conference, the measure (wins, win percentage, bowl wins, bowl win percentage, claimed or total national titles, seasons, losses) and the era it counts from (all time, or since 1912 modern rules, 1936 AP poll, 1978 Division I-A, 1998 BCS, 2014 playoff: `ERAS` in `src/lib/football.js`), the rows rank by it with competition ranks, and a program opens inline under its row. `?sort=`, `?since=<year>`, `?conf=` and `?t=<slug>` carry the board and the open program; defaults are omitted. Find (the search icon) scrolls smoothly to the picked row and focuses it; the picker skips handing focus back to its trigger after a pick, which used to snap the page back to the top. The repo is `DrewHoo/cfb-all-time-records`; `package.json` "name" is the URL slug.
- Redesigned 2026-10-21 in the house style the drewhoover.com sports sites share (College Football Streak King, `~/Projects/cfb-streak-king`, is the canon for chrome): the dark palette, Georgia Bold h1 and h2, Graduate numbers, Source Serif words, Plex Mono labels, Radix `Picker.jsx` for every select, the dateline icon bar (find a program, Ko-fi, share), What to read next, the citing ask, Method, footer. The same day the championship grid left this repo: the old grid (23 sports, 1990 on) lives on as collegiate-championships (`~/Projects/collegiate-championships`, https://drewhoover.com/collegiate-championships/), now 33 sports from 1972.
- Data: every record is the NCAA's count (vacated wins out, forfeits to the team awarded them, seasons below the top division in, junior-college and rugby seasons out). `src/data/eras.json` is each program's NCAA total through 2024 (Wikipedia's FBS win-loss table at revision 1304394366, the last before the 2025 season; the table was updated only through week 3 of 2025 after it, and the live board undercounted 2025 until 2026-10-30) and its sums from each era's first season; `src/data/current.json` is every season after 2024 counted from College Football Streak King's published payload (`https://drewhoover.com/cfb-streak-king/share/payload.json`) by `scripts/build-current.mjs`; `src/data/football.json` is each program's conference, ESPN id and slug, bowl record (Wikipedia's list of FBS bowl records) and titles through 2025. `src/lib/football.js` adds `current` to the total and to each era (a season with a game played counts as a season played). The deploy workflow refreshes `current.json` on its Sunday and Monday schedule, in season, without committing it; commit it by hand with `node scripts/build-current.mjs`. Every 'through' the page says is `F.THROUGH`, the date of the latest game (index.html's head says `%THROUGH%`, which `vite.config.js` fills); `public/logos-color/` is Streak King's mark set. Win percentage counts a tie as half a win; claimed titles are the school's own count, unclaimed selections the seasons a recognized selector named it champion. `src/lib/football.js` is pure (the measures, the eras, the URL codec, the ranking) and is shared by the page, the prerender, the card generator and the worker; `src/lib/share.js` words every title, claim and card (`F.measure(sort, since)`: "all-time wins", "wins since 1978").
- The seasons: `npm run build:seasons` (`scripts/build-seasons.mjs`, by hand, not in CI) joins Streak King's games (every top-division season from 1936), each program's "List of … football seasons" on Wikipedia (pinned in `data/season-pages.json`; pages saved under `data/build/`, not committed; `--fetch` downloads them) and James Howell's pages from a cfb-streak-king checkout beside this one (early ties a list drops; every bowl by season), under `data/season-rulings.json` (forfeits, vacated wins, missing seasons, uncounted seasons, bowl changes, `since` for an NCAA action after the table's revision, `unplaced` for a program whose seasons miss its total by more than the slack, each with receipts). It fails unless every program's seasons sum to its NCAA total within 4 games or carry an `unplaced` ruling; a ruling that changes nothing is stale and fails too. It writes `data/seasons.json` (every season) and `src/data/eras.json`; `data/build/review.txt` lists each season where the list and the games disagree with the list's footnotes, the candidates for a ruling. `npm run check:receipts` string-matches every quote against `data/receipt-pages/` (committed; drop a `.txt` there for a page a script can't read, like the Texas State fact book PDFs). When a new season ends, either move the base forward (a clean revision of the table after its bowls) or keep counting from the games; vacated wins announced later go in `since` and a season ruling.
- Build: `npm install`, `npm run dev` (http://localhost:5173/cfb-all-time-records/; `.claude/launch.json` has the dev, preview and worker entries), `npm run build` (vite build, then `scripts/prerender.mjs` bakes the board's markup, JSON-LD, the index site's embeds with `data-section="sports"`, `dist/sitemap.xml` and `dist/llms.txt` from `scripts/lib/llms.mjs`), `npm run preview` (dist at 4173). There is no typecheck or test script; the build is the check. Nothing reads `window` during render: the URL is applied once after mount so the hydrate matches the prerender. `npm run gen:og` redraws `public/og.png` and `public/card.png` (committed) on a Mac.
- The share worker: `workers/share/` (name `cfb-all-time-records-share`) sits on `drewhoover.com/cfb-all-time-records/*` in front of GitHub Pages. For an address that says more than the root (`?sort=`, `?since=`, `?conf=`, `?t=`) it rewrites `<head>` with the site's own words and points `og:image` at `share/og.png?…`, drawn on demand with workers-og and cached at the edge; crawler fetches are counted in Mixpanel as `share unfurl` and `share card`. Bump `CARD_VERSION` in `workers/share/index.ts` with any change to what a card draws or how the URL is read (it keys the cache). Local: `npm run build && npm run preview`, then `npm run worker:dev` (http://localhost:8787/cfb-all-time-records/share/og.png?sort=winPct&conf=SEC&t=alabama). `deploy.yml` deploys it after every push to `main` (`CLOUDFLARE_API_TOKEN` secret).
- Old addresses: the board lived at `/football.html`, and the index site's card still links there, so the redirect must keep working. The worker answers `/football.html` with a 301 to the root, query kept, and `public/football.html` covers the origin itself (a meta refresh and `location.replace`, hash kept). A `?s=<sport>` address (the old grid) 301s to collegiate-championships.
- Chrome shared with the siblings (the parity brief of 2026-10-22): the back bar is `data-section="sports"`; Ko-fi is `KOFI_URL` in `Notes.jsx`, three placements each `track('kofi', { from })` (`icons board`, `notes`, `footer`); `SIBLINGS` in `Notes.jsx` lists every other sports site in the shared order and wording, tracked `readnext`, and is what `llms.txt` lists too; the Method is one open paragraph with the Wikipedia credit, then `<details>` sections (where the records come from, what counts, what the words mean, where a published number differs). Share is `useShare` (the native sheet, else copy and flash copied), tracked `share`.
- Prose follows the page's own copy: plain words, one fact per sentence, no internal vocabulary on the page. Commit subjects in plain words, no prefixes; push straight to `main`.
