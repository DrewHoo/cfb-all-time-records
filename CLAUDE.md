# Project notes for the agent

- What it is: CFB All-Time Records, all 136 FBS football programs on one board at https://drewhoover.com/cfb-all-time-records/. The sentence picks the conference and the measure (all-time wins, win percentage, bowl wins, bowl win percentage, claimed or total national titles, seasons, losses), the rows rank by it with competition ranks, and a program opens inline under its row. `?sort=`, `?conf=` and `?t=<slug>` carry the board and the open program; defaults are omitted. The repo is `DrewHoo/cfb-all-time-records`; `package.json` "name" is the URL slug.
- Redesigned 2026-10-21 in the house style the drewhoover.com sports sites share (College Football Streak King, `~/Projects/cfb-streak-king`, is the canon for chrome): the dark palette, Georgia Bold h1 and h2, Graduate numbers, Source Serif words, Plex Mono labels, Radix `Picker.jsx` for every select, the dateline icon bar (find a program, Ko-fi, share), What to read next, the citing ask, Method, footer. The same day the championship grid left this repo: the old grid (23 sports, 1990 on) lives on as collegiate-championships (`~/Projects/collegiate-championships`, https://drewhoover.com/collegiate-championships/), now 33 sports from 1972.
- Data: `src/data/football.json`, Wikipedia's list of FBS football programs (CC BY-SA 4.0) through the 2025 season, with each program's ESPN id and slug; `public/logos-color/` is Streak King's mark set. Win percentage counts a tie as half a win; claimed titles are the school's own count, unclaimed selections the seasons a recognized selector named it champion; vacated games stay in, as Wikipedia's table keeps them. `src/lib/football.js` is pure (the measures, the URL codec, the ranking) and is shared by the page, the prerender, the card generator and the worker; `src/lib/share.js` words every title, claim and card.
- Build: `npm install`, `npm run dev` (http://localhost:5173/cfb-all-time-records/; `.claude/launch.json` has the dev, preview and worker entries), `npm run build` (vite build, then `scripts/prerender.mjs` bakes the board's markup, JSON-LD, the index site's embeds with `data-section="sports"`, `dist/sitemap.xml` and `dist/llms.txt` from `scripts/lib/llms.mjs`), `npm run preview` (dist at 4173). There is no typecheck or test script; the build is the check. Nothing reads `window` during render: the URL is applied once after mount so the hydrate matches the prerender. `npm run gen:og` redraws `public/og.png` and `public/card.png` (committed) on a Mac.
- The share worker: `workers/share/` (name `cfb-all-time-records-share`) sits on `drewhoover.com/cfb-all-time-records/*` in front of GitHub Pages. For an address that says more than the root (`?sort=`, `?conf=`, `?t=`) it rewrites `<head>` with the site's own words and points `og:image` at `share/og.png?…`, drawn on demand with workers-og and cached at the edge; crawler fetches are counted in Mixpanel as `share unfurl` and `share card`. Bump `CARD_VERSION` in `workers/share/index.ts` with any change to what a card draws or how the URL is read (it keys the cache). Local: `npm run build && npm run preview`, then `npm run worker:dev` (http://localhost:8787/cfb-all-time-records/share/og.png?sort=winPct&conf=SEC&t=alabama). `deploy.yml` deploys it after every push to `main` (`CLOUDFLARE_API_TOKEN` secret).
- Old addresses: the board lived at `/football.html`, and the index site's card still links there, so the redirect must keep working. The worker answers `/football.html` with a 301 to the root, query kept, and `public/football.html` covers the origin itself (a meta refresh and `location.replace`, hash kept). A `?s=<sport>` address (the old grid) 301s to collegiate-championships.
- Chrome shared with the siblings (the parity brief of 2026-10-22): the back bar is `data-section="sports"`; Ko-fi is `KOFI_URL` in `Notes.jsx`, three placements each `track('kofi', { from })` (`icons board`, `notes`, `footer`); `SIBLINGS` in `Notes.jsx` lists every other sports site in the shared order and wording, tracked `readnext`, and is what `llms.txt` lists too; the Method is one open paragraph with the Wikipedia credit, then `<details>` sections (where the records come from, what counts, what the words mean, where a published number differs). Share is `useShare` (the native sheet, else copy and flash copied), tracked `share`.
- Prose follows the page's own copy: plain words, one fact per sentence, no internal vocabulary on the page. Commit subjects in plain words, no prefixes; push straight to `main`.
